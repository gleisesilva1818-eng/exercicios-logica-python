# Exercícios de Programação - Faculdade Cruzeiro do Sul 🎓

Este repositório registra meus primeiros passos práticos na programação, desenvolvidos como parte da graduação em Análise e Desenvolvimento de Sistemas (ADS). Como estudante em transição de carreira, utilizo este espaço para documentar minha evolução e o domínio dos fundamentos de Python.

## 📂 Exercícios Inclusos

### 01. Conversor de Temperatura
* **Descrição:** Script que realiza a conversão de Celsius para Fahrenheit.
* **Conceitos:** Interação com o usuário via terminal, operadores aritméticos e organização de código.

### 02. Cálculo de Fatorial
* **Descrição:** Algoritmo para calcular o fatorial de números inteiros entre 1 e 10.
* **Conceitos:** Importação de bibliotecas nativas (`math`), conversão de tipos de dados (casting) e exibição de resultados com f-strings.

---

## 💡 Reflexão sobre o Aprendizado

Como estou no início da minha jornada na tecnologia, estes exercícios foram fundamentais para entender como a lógica de programação funciona na prática. 

O maior aprendizado foi compreender o fluxo de dados: desde a entrada pelo usuário, a necessidade de converter textos em números (**casting**) para realizar cálculos, até a exibição final. Optei por utilizar variáveis autodescritivas (como `resultado_fatorial`) e comentários detalhados para garantir que o código seja legível, demonstrando minha preocupação com a organização e clareza desde os meus primeiros scripts.
